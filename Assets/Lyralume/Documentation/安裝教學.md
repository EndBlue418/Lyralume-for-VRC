# Lyralume 1.0.0 安裝教學

Created by EndBlue · Assisted by Codex

## 準備

使用 Unity 2022.3 的 VRChat Worlds 專案，先安裝 Worlds SDK、VizVid 與 AudioLink。需要 LTCGI、VRCLV 或 LuraSwitch 2 時，先自行安裝對應工具。本套件不附第三方工具本體。

## 安裝歌詞

1. 匯入 Lyralume-1.0.0.unitypackage，等待 Unity 與 Udon 編譯完成。
2. 開啟 Tools → Lyralume → 安裝與設定。
3. 指定場景中的 VizVid 播放器，勾選要使用的 VizVid 螢幕，再安裝。
4. 在 API 網址與優先順序填入自己的相容服務，再套用到場景。
5. 儲存場景，使用 VRChat SDK 的 Build & Test 測試播放。

API 預設空白。服務必須支援本系統的 /api/proxy 與 /api/udon 協定；原始音樂服務 API 不能直接替代。可設定多個站點、優先順序及啟用狀態。未設定 API 時，不會自動發送歌詞請求。

一套 Lyralume 對應一台 VizVid，可選多個螢幕。多台播放器請分別用工具安裝，不要直接複製已配置的實例。各自的歌詞音樂反應會自動分析自己的音源；地圖原有共用 AudioLink 的路由保留。

選取 Lyralume 根物件可調整自動歌詞、預讀、逐字高亮、翻譯、羅馬音與封面。工具會配置字型、材質、相機及 RenderTexture。

## 選裝 Debug

開啟 Tools → Lyralume → 安裝 Debug 監看器，指定要監看的 Lyralume。

標準分體版使用 LuraSwitch 2：左側螢幕、右側 Runtime，按鈕與滑桿整合於 Runtime，外側 Debug 按鈕在右邊。沒有安裝 LuraSwitch 時，可選簡易 Unity UI 版。

「遊戲開始時顯示 Debug」預設關閉。每套 Debug 可分別指定監看對象，也可調整 Default Open。關閉時停止監看刷新與預覽相機。

## LTCGI 與 VRCLV

世界已安裝 LTCGI 或 VRCLV 時，安裝工具會嘗試連接所選 VizVid 的既有配置。無法唯一判定的自訂配置，可展開進階設定指定。歌詞接管期間輸出歌詞畫面，退出時還原原生播放輸出。

各套主顯示與 Debug 需要獨立的渲染圖層，使用可用的 22–30 層；不足時工具會提示。Debug 預設關閉仍會保留其圖層。

## 圖片 Prefab

位置：Modules/dev.endblue.lyralume/Runtime/Branding/Prefabs。

- Lyralume-Player：播放器標誌。
- Lyralume-Powered：Powered by 標示。
- Lyralume-Purple-Branding：紫色作者介紹圖。

皆為正確原圖比例的透明 Quad，可直接拖入場景並等比例縮放。三張作者提供的原始 PNG 均包含在 Branding 資料夾。

## 更新與檢查

更新既有安裝前先備份專案，匯入後等待編譯，再重新 Build & Test。匯入不會自動重排場景或填入 API。請勿同時安裝相同程式的其他來源副本。

安裝後先確認主螢幕、Debug、翻譯、音樂反應及原有照明，再發佈世界。
